Question ID: CUET-MATH-2026-084 • Level: Medium • Select an option to test your answer:

Evaluate the definite improper integral: ∫0∞ x · e−2x dx.

Click to View Step-by-Step Derivation & Correct Option

Correct Answer: B) 1/4

Derivation: Using the standard Gamma function identity: ∫0∞ xn−1 e−αx dx = Γ(n) / αn. Here n = 2 and α = 2. Therefore, Γ(2) / 22 = 1! / 4 = 1/4.
