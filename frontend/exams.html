CUET PG — Common University Entrance Test (Postgraduate)

Target Aspirants: MCA, M.Sc Computer Science, and Central University Postgraduate Candidates.

Test Duration:
105 Minutes (1 Hour 45 Minutes)
Total Questions:
75 Domain-Specific Multiple Choice Questions (MCQs)
Marking Scheme:
+4 Marks for each correct answer; −1 Mark for each incorrect attempt (Negative Marking).

Core Syllabus Modules:

  • Mathematics: Set Theory, Coordinate Geometry, Calculus, Probability, Linear Algebra.
  • Data Structures & Algorithms: Arrays, Stacks, Queues, Binary Trees, Graphs, Sorting & Searching Complexity.
  • Computer Architecture & OS: Memory hierarchy, Process management, Boolean Algebra, Logic Gates.
  • Database Management: Relational Model, SQL queries, Normalization, ER diagrams.
